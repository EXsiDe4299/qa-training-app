# QA Training App

Небольшое веб-приложение для практики тестирования: регистрация, вход, создание и удаление заявок.

## Возможности

- Регистрация и вход по логину и паролю
- Сессия в cookie после успешного входа
- Создание заявок (заголовок + описание)
- Список всех заявок
- Удаление только своих заявок
- Выход из аккаунта

## Правила, которые стоит покрыть тестами

- Логин: минимум 3 символа
- Пароль: минимум 6 символов
- Повторная регистрация с тем же логином возвращает ошибку
- Нельзя создать заявку с пустым заголовком или описанием (в том числе из пробелов)
- Неавторизованный пользователь не видит список заявок и перенаправляется на `/login`
- Удалить заявку может только автор

## Запуск

```bash
uv sync --group dev
uv run qa-training-app
```

Приложение откроется на [http://127.0.0.1:8000](http://127.0.0.1:8000).

OpenAPI-документация: [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs).

## Тесты

Сначала один раз установите браузеры Playwright:

```bash
uv run playwright install chromium
```

Запуск:

```bash
uv run pytest
```

E2E-тесты используют `pytest-playwright`. Сервер и тестовая БД поднимаются автоматически в `tests/conftest.py`. Перед каждым тестом база очищается.

## Селекторы для UI-тестов

В разметке есть стабильные `data-testid`. Примеры:

- `login-form`, `register-form`, `request-form`
- `username-input`, `password-input`
- `error-message`
- `current-username`, `logout-button`
- `requests-list`, `empty-state`, `request-card`
- `delete-request-button`
